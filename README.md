# Arabic AI Feedback Analyzer

An Arabic feedback analysis application built with Python and Streamlit.

## Features
- Analyze Arabic customer feedback.
- Classify feedback as Positive, Negative, or Neutral.
- Display sentiment statistics and charts.
- Identify the most frequent words.
- Export analysis results to CSV.

## Technologies
- Python
- Streamlit
- Pandas
- Matplotlib

## How to Run
1. Install the required libraries:
   `pip install -r requirements.txt`
2. Run the application:
   `streamlit run app.py`

## Project Note
Sentiment classification currently uses predefined Arabic keywords. It is a rule-based approach, not a trained machine learning model.
